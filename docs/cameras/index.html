Docs / Cameras

Supported cameras

GRKit runs on these cameras and firmware versions.

CameraFirmware
GR III / GR III HDF2.10 / 2.20 / 2.21
GR IIIx / GR IIIx HDF1.60 / 1.70 / 1.71
GR IV / GR IV HDF1.11 / 1.20 / 1.21
GR IV Monochrome1.00 / 1.10 / 1.11
GR IV MonochromeIt has every GRKit module except Film Look, because the film looks are made for color sensors.

Earlier GR models and other cameras are not supported. GRKit runs only on the official Ricoh firmware and on the fast-boot firmware of grkit.app.
