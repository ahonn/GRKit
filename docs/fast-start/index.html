Docs / Cameras

Fast start

The optional fast-boot firmware loads GRKit one to two seconds after power-on.

This changes the camera firmwareYou update the camera with a firmware file that Ricoh did not make. If the update stops, the camera may not start. Ricoh may decline warranty or repair service for a camera that used modified firmware.

Install it

  1. Download the latest firmware ZIP of your camera from Ricoh.
  2. On the Fast start page, select the ZIP. The page makes the fast-boot firmware on your device.
  3. Charge the battery fully and copy your photos from the card.
  4. Copy the fast-boot firmware file to the card root. Remove other .bin files.
  5. Turn the camera off. Hold MENU and press the power button. Follow the screen.
  6. Do not turn the camera off or open the battery/card cover until the update is complete.
  7. Turn the camera on and make sure that it takes photos and plays them back.
  8. Delete the firmware file from the card. Then install the latest GRKit.

Go back to the official firmware

Install the official firmware file of the same version in the same way. A later official update also replaces the fast-boot firmware.
