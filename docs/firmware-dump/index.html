Docs / Cameras

Firmware dump

The dump tool helps the developer support a firmware build that GRKit does not know yet.

Before you startThe tool only reads memory, and the files have no photos or personal data. SD scripts must be on. While the tool is on the card, GRKit does not load. Use a charged battery.

Dump the firmware

  1. Download GRKit-<version>-dump.zip from the latest release.
  2. Turn the camera off and remove the card.
  3. Copy the SCRIPT folder of the card to your computer as a backup.
  4. Copy the contents of SD_ROOT from the ZIP to the card root. Replace SCRIPT/STARTUP.TTL.
  5. Insert the card and turn the camera on normally. Do not hold MENU.
  6. Wait 2 minutes. Then turn the camera off.
  7. On a computer, open SCRIPT/GRDUMP. The folder has DUMP.OK or DUMP.ERR.
  8. Zip SCRIPT/GRDUMP and attach it to a GitHub issue, with the camera model and firmware version.

Restore the card

Delete the SCRIPT folder from the card. Then copy the SCRIPT folder from your backup to the card.
