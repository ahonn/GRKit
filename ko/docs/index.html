GRKit 문서

GRKit을 설치하고, 문제를 해결하고, GR의 각 설정을 알아봅니다.

GRKit은 메모리 카드에서 실행되며 펌웨어에 쓰지 않습니다. 선택 사항인 빠른 시작 펌웨어만 펌웨어를 바꿉니다.
