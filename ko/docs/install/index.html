GRKit 설치

GRKit을 메모리 카드에 기록한 뒤 SD 스크립트를 한 번 켭니다.

카드에 기록

컴퓨터의 Chrome이나 Edge와 카드 리더를 사용합니다. 카메라의 USB 연결로는 기록할 수 없습니다.

  1. 설치 페이지를 엽니다. 카메라, 펌웨어, 모듈, 필름 룩을 선택합니다.
  2. SD 카드 연결을 선택합니다. 카드 자체를 선택한 뒤 편집을 허용합니다.
  3. 변경 사항을 확인하고 카드에 기록합니다. 사진은 카드에 그대로 남습니다.

다른 브라우저

  1. 설치 페이지에서 GRKit.zip을 다운로드합니다.
  2. SD_ROOT 폴더 자체가 아니라 그 내용을 카드 최상위에 복사합니다.
  3. 이제 카드 최상위에 SCRIPT 폴더가 있는지 확인합니다.

처음 시작하기

한 번만 합니다. SD 스크립트 설정은 모든 카드에 유지됩니다.

  1. 카메라의 전원을 끄고 카드를 넣습니다.
  2. MENU를 누른 채 카메라의 전원을 켭니다.
  3. 카메라에 Complete가 표시되고 전원이 저절로 꺼질 때까지 기다립니다.
  4. 평소처럼 카메라의 전원을 켭니다.
펌웨어 업데이트가 시작되면카드 최상위에 펌웨어 파일이 있습니다. 카메라의 전원을 끄고 카드 최상위에서 .bin 파일을 모두 제거한 뒤 이 단계를 다시 합니다.

GRKit 사용

GRKit은 전원을 켜고 약 8~10초 뒤에 불러와집니다. GR IV와 설치 또는 업데이트 후 처음 켤 때는 더 오래 걸립니다. 그러면 촬영 화면 위쪽에 GRKit이 표시됩니다.

  1. 촬영 모드에서 ADJ를 누르고 여섯 번째 항목인 GRK를 선택합니다.
  2. 기능을 선택하고 항목에 커서를 맞춥니다.
  3. OK를 눌러 유지합니다. 더 많은 설정은 Fn을 누릅니다.
