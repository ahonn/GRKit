지원 카메라

GRKit은 다음 카메라와 펌웨어 버전에서 실행됩니다.

카메라펌웨어
GR III / GR III HDF2.10 / 2.20 / 2.21
GR IIIx / GR IIIx HDF1.60 / 1.70 / 1.71
GR IV / GR IV HDF1.11 / 1.20 / 1.21
GR IV Monochrome1.00 / 1.10 / 1.11
GR IV Monochrome필름 룩을 제외한 모든 GRKit 모듈이 있습니다. 필름 룩은 컬러 센서용으로 만들어졌습니다.

이전 GR 모델과 다른 카메라는 지원하지 않습니다. GRKit은 Ricoh 공식 펌웨어와 grkit.app의 빠른 시작 펌웨어에서만 실행됩니다.
