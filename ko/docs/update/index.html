문서 / 시작하기

업데이트 또는 제거

업데이트해도 설정과 필름 룩은 유지됩니다. MENU를 다시 누를 필요는 없습니다.

사이트에서 업데이트

  1. 카드를 카드 리더에 넣고 Chrome이나 Edge에서 설치 페이지를 엽니다.
  2. SD 카드 연결을 선택하고 변경 사항을 확인한 뒤 카드에 기록합니다.
  3. 카드를 카메라에 넣고 전원을 켭니다.

ZIP으로 업데이트

  1. 카드에서 SCRIPT 폴더를 삭제합니다.
  2. 새 GRKit.zip의 SD_ROOT에서 SCRIPT 폴더만 카드 최상위에 복사합니다.
  3. 카드를 카메라에 넣고 전원을 켭니다. MENU는 누르지 마십시오.

GRKit 제거

설치 페이지에서 카드를 연결하고 GRKit 제거를 선택합니다. 또는 SCRIPT 폴더와 GRKIT 폴더를 삭제합니다. 사진은 그대로 남습니다. GRKIT에는 GRKit 설정이 들어 있습니다.

SD 스크립트 끄기

GRKit을 제거해도 이 설정은 켜져 있습니다. GRKit을 더 이상 쓰지 않을 때만 끕니다.

  1. 설치 페이지에서 사용하는 카메라의 SD 스크립트를 끄는 파일을 다운로드합니다.
  2. SD_ROOT의 내용을 카드 최상위에 복사합니다.
  3. 카드를 넣습니다. MENU를 누른 채 카메라의 전원을 켭니다.
  4. 카메라의 전원이 저절로 꺼질 때까지 기다립니다.
  5. 카드 최상위에서 ModeSet 파일과 DEVELOP.MOD를 제거합니다.
