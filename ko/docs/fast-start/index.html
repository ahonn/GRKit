문서 / 카메라

빠른 시작

선택 사항인 빠른 시작 펌웨어를 쓰면 전원을 켜고 1~2초 뒤에 GRKit을 불러옵니다.

카메라 펌웨어가 바뀝니다Ricoh가 만들지 않은 펌웨어 파일로 카메라를 업데이트합니다. 업데이트가 중간에 멈추면 카메라가 켜지지 않을 수 있습니다. 수정된 펌웨어를 쓴 카메라는 Ricoh의 보증이나 수리를 받지 못할 수 있습니다.

설치

  1. Ricoh에서 카메라의 최신 펌웨어 ZIP을 다운로드합니다.
  2. 빠른 시작 페이지에서 ZIP을 선택합니다. 페이지가 사용 중인 기기 안에서 빠른 시작 펌웨어를 만듭니다.
  3. 배터리를 완전히 충전하고 카드의 사진을 복사해 둡니다.
  4. 빠른 시작 펌웨어 파일을 카드 최상위에 복사합니다. 다른 .bin 파일은 제거합니다.
  5. 카메라의 전원을 끕니다. MENU를 누른 채 전원 버튼을 누릅니다. 화면 안내를 따릅니다.
  6. 업데이트가 끝날 때까지 카메라를 끄거나 배터리/카드 커버를 열지 마십시오.
  7. 카메라의 전원을 켜고 촬영과 재생이 되는지 확인합니다.
  8. 카드에서 펌웨어 파일을 삭제합니다. 그런 다음 최신 GRKit을 설치합니다.

공식 펌웨어로 돌아가기

같은 버전의 공식 펌웨어 파일을 같은 방법으로 설치합니다. 이후의 공식 업데이트도 빠른 시작 펌웨어를 대체합니다.
