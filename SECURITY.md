# Security policy

## Report a problem

Do not open a public issue for a security problem. Report it privately with GitHub private vulnerability reporting: open the Security tab of this repository and select "Report a vulnerability".

Report a problem of these types:

- A package or an effect file stops the camera during startup.
- A package or an effect file corrupts files on the card.
- A package or an effect file runs code that GRKit does not intend to run.
- A problem on the site changes the contents of a downloaded package.

Give the camera model, the firmware version, the SHA-256 of `GRKit.zip`, and the steps that cause the problem.

If your camera does not start, read the [recovery guide](resources/RECOVERY.md) before you do other steps.

## Supported versions

The maintainers fix problems in `main` and in the current release of the site. Earlier packages do not get fixes. Download a new package after a fix.
