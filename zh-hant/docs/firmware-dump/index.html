韌體匯出

韌體匯出工具協助開發者支援 GRKit 還不認識的韌體組建。

開始之前這個工具只讀取記憶體，匯出的檔案不包含照片和個人資料。SD 腳本必須已開啟。工具在記憶卡上時，GRKit 不會載入。請使用充飽電的電池。

匯出韌體

  1. 從最新版本下載 GRKit-<version>-dump.zip。
  2. 關閉相機，取出記憶卡。
  3. 把記憶卡上的 SCRIPT 資料夾複製到電腦，作為備份。
  4. 把 ZIP 中 SD_ROOT 的內容複製到記憶卡根目錄，並取代 SCRIPT/STARTUP.TTL。
  5. 插入記憶卡，正常開機，不要按住 MENU。
  6. 等待 2 分鐘，然後關機。
  7. 在電腦上開啟 SCRIPT/GRDUMP。資料夾中會有 DUMP.OK 或 DUMP.ERR。
  8. 把 SCRIPT/GRDUMP 壓縮成 ZIP，附加到 GitHub issue，並寫明相機型號和韌體版本。

還原記憶卡

從記憶卡刪除 SCRIPT 資料夾，然後把備份的 SCRIPT 資料夾複製到記憶卡。
