模式轉盤與 U1–U3

在每個轉盤位置開啟或關閉 GRKit，並把風格儲存到 U1、U2 或 U3。

位置
MENU › GRKit › GRKit 設定 › 模式轉盤

P、Av、Tv、M 和 Sn（GR IV）共用一組 GRKit 設定。每個位置各有自己的開啟或關閉。

U1、U2 和 U3

  • 開啟使用共用的 GRKit 設定。
  • 關閉讓這個位置不使用 GRKit。
  • 儲存目前設定把相機和 GRKit 設定儲存到這個位置。
在相機功能表中儲存如果在相機功能表中再次儲存 USER 模式，這個位置會失去它的 GRKit 風格。要保留風格，請使用儲存目前設定。
