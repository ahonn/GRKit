更新或移除

更新會保留你的設定和底片風格，不需要再按住 MENU。

從網站更新

  1. 把記憶卡插入讀卡機，用 Chrome 或 Edge 開啟安裝頁。
  2. 選擇連接 SD 卡，檢查變更，然後寫入記憶卡。
  3. 把記憶卡插入相機並開機。

用 ZIP 更新

  1. 從記憶卡刪除 SCRIPT 資料夾。
  2. 從新 GRKit.zip 的 SD_ROOT 中，只把 SCRIPT 資料夾複製到記憶卡根目錄。
  3. 把記憶卡插入相機並開機，不要按住 MENU。

移除 GRKit

在安裝頁連接記憶卡，然後選擇解除安裝 GRKit。或者刪除 SCRIPT 和 GRKIT 資料夾。照片不受影響。GRKIT 中保存著你的 GRKit 設定。

關閉 SD 腳本

移除 GRKit 後，這個設定仍保持開啟。只有永久停用 GRKit 時才需要關閉。

  1. 在安裝頁下載適用於你相機的關閉 SD 腳本檔案。
  2. 把 SD_ROOT 中的內容複製到記憶卡根目錄。
  3. 插入記憶卡，按住 MENU 開機。
  4. 等待相機自動關機。
  5. 從記憶卡根目錄刪除 ModeSet 檔案和 DEVELOP.MOD。
