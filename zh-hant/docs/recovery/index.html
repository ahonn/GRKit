文件 / 解決問題

相機在啟動時停止回應

GRKit 只在相機開機期間修改相機，關機後修改即失效。它不會寫入韌體。

開始之前不要推或拉鏡頭筒。官方韌體升級期間不要斷電。

不插記憶卡開機

  1. 嘗試關閉相機。
  2. 如果相機沒有反應，取出電池。電池可能會很熱。
  3. 取出記憶卡。
  4. 裝入充飽電的電池。不插記憶卡開機。

如果相機還是無法啟動

  1. 不插記憶卡，長按重播按鈕，讓相機以重播模式開啟。
  2. 如果能開啟功能表，請選擇重設。GR IV 請選擇重設設定，不要選擇重設至出廠預設值，它還會刪除內部記憶體中的影像。重設會刪除你的個人設定。
  3. 不插記憶卡，再次開機。
如果仍然無法啟動請停止使用 GRKit，並聯絡相機維修中心。
