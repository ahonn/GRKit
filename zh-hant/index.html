在相機裡

安裝前須知

要付費嗎？

不用。GRKit 免費開源，原始碼在 GitHub 上，採用 MIT 授權，也不需要註冊帳號。

會不會弄壞相機？

GRKit 從記憶卡載入，不修改韌體，除非你自己選擇安裝選用的快速啟動韌體。取出記憶卡，相機就恢復原樣。GRKit 不提供任何擔保。

支援哪些相機？

GR III、GR IIIx、GR IV 及它們的 HDF 版本；GR IV Monochrome 也能用，但沒有底片風格。支援的韌體版本請見安裝頁。更早的 GR 機型不支援。

需要準備什麼？

一張 SD 卡和一個讀卡機。在電腦上用 Chrome 或 Edge，可以直接把 GRKit 寫入記憶卡；其他瀏覽器可以下載 GRKit.zip，再複製到卡裡。

會改動 RAW 檔嗎？

不會。GRKit 只改 JPEG，RAW（DNG）檔保留相機的原始資料。

會拖慢相機嗎？

開機後約 8 到 10 秒 GRKit 才載入完成，在此之前相機使用自己的設定。裝上選用的快速啟動韌體後，一到兩秒就能載入。

怎麼移除？

在安裝頁移除，或刪除記憶卡上的 GRKIT 和 SCRIPT 資料夾即可。照片不受影響。
