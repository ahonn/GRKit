安裝

  1. 關閉相機。
  2. 開啟 GRKit.zip（有些瀏覽器會自動解壓縮），把 SD_ROOT 裡面的內容（不是這個資料夾本身）複製到記憶卡根目錄。複製後，根目錄裡應有 SCRIPT 資料夾。
  3. 插入記憶卡。僅首次使用時：按住 MENU 按鈕開機，等待相機自動關機。這一步需要 00078350.588 和 DEVELOP.MOD。
  4. 正常開機。GRKit 在開機後約 8 到 10 秒載入，之後在拍攝時按 ADJ，選擇第 6 項 GRK。

    想更快載入 GRKit？試試快速啟動。

  5. 選用：從記憶卡根目錄刪除 00078350.588 和 DEVELOP.MOD，以後更新也不需要它們。

更新

  1. 關閉相機。
  2. 從記憶卡刪除 SCRIPT 資料夾。
  3. 開啟新的 GRKit.zip，只把 SD_ROOT 中的 SCRIPT 資料夾複製到記憶卡根目錄。
  4. 插入記憶卡，正常開機，不需要按住 MENU。
  5. 卡上已有的底片風格會保留。不想要的底片風格，可以在 MENU GRKit 小節中底片風格的「可選項」裡隱藏。

解除安裝

  1. 關閉相機。從記憶卡刪除 SCRIPT 和 GRKIT 資料夾。GRKIT 保存 GRKit 的設定。
  2. 如需同時關閉 SD 腳本，下載下方的檔案，把 SD_ROOT 中的內容複製到記憶卡根目錄。
  3. 插入記憶卡。按住 MENU 按鈕開機，等待相機自動關機。
  4. 從記憶卡根目錄刪除 00078350.588 和 DEVELOP.MOD。

常見問題

ADJ 裡沒有 GRK？

GRKit 在開機後約 8 到 10 秒載入，GR IV 以及安裝或更新後的第一次開機會更久。稍等片刻，然後在拍攝時按 ADJ，選擇第 6 項 GRK。首次使用前，需要按住 MENU 開機，開啟 SD 腳本。想更快載入，可以試試快速啟動。

為什麼開機後頭幾張照片沒有底片風格？

GRKit 載入完成前，相機使用原本的設定。開機後稍等幾秒再拍，或者試試快速啟動。

GRKit 會修改相機韌體嗎？

不會。GRKit 在開機時從記憶卡載入。取出記憶卡或解除安裝 GRKit 後，相機和原來一樣。SD 腳本設定（讓相機從記憶卡執行 GRKit）會一直開啟，直到你關閉它。只有選用的快速啟動韌體會修改韌體，而且只在你安裝它之後。

能讓 GRKit 載入得更快嗎？

可以，使用選用的快速啟動韌體。它需要更新一次韌體。

底片風格會改掉我的 影像控制 設定嗎？

不會。開啟底片風格時，會取代影像控制；關閉後，原本的影像控制設定就會恢復。

格式化記憶卡會怎樣？

格式化會刪除 GRKit 及其設定。格式化前，請把 GRKIT 資料夾複製到電腦。格式化後，重新安裝 GRKit，再把 GRKIT 資料夾複製回記憶卡根目錄。

更新或換卡後，還要按住 MENU 開機嗎？

不用。只有首次使用時需要按住 MENU 開機，開啟 SD 腳本。這個設定對所有記憶卡都有效。

能用我自己的 LUT 或 Lightroom 預設集嗎？

可以。在「底片風格」中選擇「匯入 LUT」。Lightroom 預設集的轉換方法見匯入視窗中的說明。

能在 Lightroom 裡使用這些風格嗎？

不能直接使用，GRKit 不提供 Lightroom 預設集。這些風格來自開源的底片 LUT，頁面底部的「底片風格授權」列出了每個風格的來源。

GRKit 支援哪些相機？

GR III、GR IIIx、GR IV 及其 HDF 機型，以及 GR IV Monochrome（不含底片風格），韌體版本見相機列表。更早的 GR 機型不支援。

卡上裝的是哪個版本？

在相機上開啟 MENU，「自定義設定」功能表中 GRKit 小節的最後有「關於 GRKit」。
