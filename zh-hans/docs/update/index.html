文档 / 快速上手

更新或移除

更新会保留你的设置和胶片风格，不需要再按住 MENU。

从网站更新

  1. 把存储卡放进读卡器，在 Chrome 或 Edge 中打开安装页面。
  2. 选择连接 SD 卡，检查改动并写入存储卡。
  3. 把存储卡放进相机并开机。

从 ZIP 更新

  1. 从存储卡删除 SCRIPT 文件夹。
  2. 从新的 GRKit.zip 的 SD_ROOT 中，只把 SCRIPT 文件夹复制到存储卡根目录。
  3. 把存储卡放进相机并开机。不要按住 MENU。

移除 GRKit

在安装页面连接存储卡，然后选择卸载 GRKit。也可以删除 SCRIPT 和 GRKIT 文件夹。照片会保留。GRKIT 中保存着你的 GRKit 设置。

关闭 SD 脚本功能

移除 GRKit 后，这个设置会保持打开。只有在你不再使用 GRKit 时，才需要关闭它。

  1. 在安装页面下载你的相机对应的关闭 SD 脚本的文件。
  2. 把 SD_ROOT 中的内容复制到存储卡根目录。
  3. 插入存储卡，按住 MENU 开机。
  4. 等待相机自动关机。
  5. 从存储卡根目录删除 ModeSet 文件和 DEVELOP.MOD。
