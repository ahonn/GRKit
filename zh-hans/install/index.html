安装

  1. 关闭相机。
  2. 打开 GRKit.zip（有的浏览器会自动解压），把 SD_ROOT 里面的内容（不是这个文件夹本身）复制到存储卡根目录。复制后，根目录里应有 SCRIPT 文件夹。
  3. 插入存储卡。仅首次使用时：按住 MENU 按钮开机，等待相机自动关机。这一步需要 00078350.588 和 DEVELOP.MOD。
  4. 正常开机。GRKit 在开机后约 8 到 10 秒加载，之后在拍摄时按 ADJ，选择第 6 项 GRK。

    想更快加载 GRKit？试试快速启动。

  5. 可选：从存储卡根目录删除 00078350.588 和 DEVELOP.MOD，以后更新也不需要它们。

更新

  1. 关闭相机。
  2. 从存储卡删除 SCRIPT 文件夹。
  3. 打开新的 GRKit.zip，只把 SD_ROOT 中的 SCRIPT 文件夹复制到存储卡根目录。
  4. 插入存储卡，正常开机，不需要按住 MENU。
  5. 卡上已有的胶片风格会保留。不想要的胶片风格，可以在 MENU GRKit 小节中胶片风格的“可选项”里隐藏。

卸载

  1. 关闭相机。从存储卡删除 SCRIPT 和 GRKIT 文件夹。GRKIT 保存 GRKit 的设置。
  2. 如需同时关闭 SD 脚本，下载下面的文件，把 SD_ROOT 中的内容复制到存储卡根目录。
  3. 插入存储卡。按住 MENU 按钮开机，等待相机自动关机。
  4. 从存储卡根目录删除 00078350.588 和 DEVELOP.MOD。

常见问题

ADJ 里没有 GRK？

GRKit 在开机后约 8 到 10 秒加载，GR IV 以及安装或更新后的第一次开机会更久。稍等片刻，然后在拍摄时按 ADJ，选择第 6 项 GRK。首次使用前，需要按住 MENU 开机，打开 SD 脚本。想更快加载，可以试试快速启动。

为什么开机后头几张照片没有胶片风格？

GRKit 加载完成前，相机使用自身的设置。开机后稍等几秒再拍，或者试试快速启动。

GRKit 会修改相机固件吗？

不会。GRKit 在开机时从存储卡加载。取出存储卡或卸载 GRKit 后，相机和原来一样。SD 脚本设置（让相机从存储卡运行 GRKit）会一直开启，直到手动关闭。只有可选的快速启动固件会修改固件，而且只在你安装它之后。

能让 GRKit 加载得更快吗？

可以，使用可选的快速启动固件。它需要更新一次固件。

胶片风格会改掉我的影像控制设置吗？

不会。打开胶片风格时，会代替影像控制；关闭后，原来的影像控制设置就会恢复。

格式化存储卡会怎样？

格式化会删除 GRKit 及其设置。格式化前，请把 GRKIT 文件夹复制到电脑。格式化后，重新安装 GRKit，再把 GRKIT 文件夹复制回存储卡根目录。

更新或换卡后，还要按住 MENU 开机吗？

不用。只有首次使用时需要按住 MENU 开机，打开 SD 脚本。这个设置对所有存储卡都有效。

能用我自己的 LUT 或 Lightroom 预设吗？

可以。在“胶片风格”中选择“导入 LUT”。Lightroom 预设的转换方法见导入窗口中的说明。

能在 Lightroom 里使用这些风格吗？

不能直接使用，GRKit 不提供 Lightroom 预设。这些风格来自开源的胶片 LUT，页面底部的“胶片风格许可”列出了每个风格的来源。

GRKit 支持哪些相机？

GR III、GR IIIx、GR IV 及其 HDF 机型，以及 GR IV Monochrome（不含胶片风格），固件版本见相机列表。更早的 GR 机型不支持。

卡上装的是哪个版本？

在相机上打开 MENU，“关于 GRKit”在自定义页 GRKit 小节的最后。
