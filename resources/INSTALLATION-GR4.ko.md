# GRKit

RICOH GR IV 및 GR IV HDF 펌웨어 1.11 전용입니다. 하나의 패키지를 지원하는 모든 펌웨어 버전에 사용할 수 있습니다. GRKit은 전원을 켤 때마다 카메라의 펌웨어를 확인합니다. 펌웨어 1.20(GR IV Monochrome은 1.10)으로의 업데이트는 되돌릴 수 없습니다. 업데이트한 뒤에도 같은 패키지를 사용할 수 있습니다. GR IV Monochrome은 GR IV의 펌웨어로 작동하며 자체 버전을 표시합니다. 펌웨어 1.11은 1.00, 펌웨어 1.20은 1.10으로 표시됩니다. GR IV Monochrome용 패키지에는 필름 룩이 없습니다. GR IV Monochrome은 GR IV의 런타임을 사용하지만, GR IV Monochrome 자체는 실제 카메라에서 테스트하지 않았습니다.

## 설치

1. 카메라의 전원을 끕니다.
2. `SD_ROOT`의 내용을 SD 카드 최상위에 복사합니다.
3. 카드를 넣습니다. MENU 버튼을 누른 채 전원을 켭니다. 카메라의 전원이 저절로 꺼질 때까지 기다립니다.
4. 평소처럼 전원을 켭니다.

3단계에서 카메라의 SD 스크립트가 켜집니다. 카메라에 Mode Set Command와 Complete가 차례로 표시된 다음, 전원이 저절로 꺼집니다.

![Mode Set Command 화면에 Script - Enable과 Complete가 표시되어 있습니다.](images/modeset.png)

SD 스크립트가 이미 켜져 있으면 3단계를 건너뜁니다. 설치 후에는 카드 최상위에서 `00078560.636`과 `DEVELOP.MOD`를 삭제해도 됩니다. 이 단계는 선택 사항입니다.

## 업데이트

1. 카메라의 전원을 끕니다.
2. 카드에서 `SCRIPT` 폴더를 삭제합니다.
3. 새 패키지의 `SD_ROOT`에 있는 `SCRIPT` 폴더를 SD 카드 최상위에 복사합니다.
4. 평소처럼 전원을 켭니다. MENU 버튼을 누를 필요는 없습니다.

GRKit은 설정, 효과, 추가한 모듈을 `GRKIT` 폴더에 저장하므로 업데이트 후에도 그대로 남습니다.

`SCRIPT`를 삭제하면 GRKit 1.2의 설정과 효과도 삭제됩니다. 이를 유지하려면 컴퓨터의 Chrome이나 Edge에서 [grkit.app](https://grkit.app)을 열고, 카드 리더에 카드를 연결해 업데이트하십시오.

## 사용 방법

촬영 모드에서 ADJ 레버를 눌러 ADJ 모드로 들어간 다음, 여섯 번째 항목인 GRK를 선택합니다. GRKit은 전원을 켜고 몇 초 뒤에 불러와지므로 이 항목이 늦게 표시될 수 있습니다. 불러오기가 끝나면 촬영 화면 위쪽에 **GRKit**이 몇 초 동안 표시됩니다. 이 표시에는 프레이밍 또는 구도 가이드 모듈이 필요합니다.

- **필름 룩(Film Look):** 효과에 커서를 맞추면 미리 보기가 표시됩니다. OK 버튼을 누르면 확정됩니다. Fn 버튼을 누르면 그 효과의 [표준] 파라미터를 조정할 수 있습니다. GRK 메뉴의 필름 룩 행에서 Fn 버튼을 누르면 선택한 효과를 조정할 수 있습니다. 조정 내용은 효과마다 저장되며, 카메라의 화상 컨트롤 설정은 바뀌지 않습니다. 효과는 GR III에 맞춰 만들어졌으므로 GR IV에서는 색이 다를 수 있습니다.
- **프레이밍(Framing):** XPan, 2.35:1, 16:9, 4:3, 5:4, 7:6, 1:1 중에서 선택합니다. 어떤 비율을 선택해도 [화상비율]이 3:2가 됩니다. 촬영 화면은 3:2로 유지되고 사진 범위 밖이 어둡게 표시됩니다. XPan과 2.35:1은 [화상비율]이 16:9일 때도 작동합니다. 카메라 메뉴에서 [화상비율]을 다른 값으로 바꾸면 프레이밍은 일시적으로 꺼집니다. DNG 파일에는 센서 전체의 화상이 남고, 크롭 범위가 기록됩니다. 기록된 크롭 범위를 적용하는 RAW 현상 소프트웨어에서는 사진 범위만 표시됩니다.
- **구도 가이드(Guides):** 가이드 종류를 선택합니다. Fn 버튼을 누르면 선의 색상, 불투명도, DISP로 촬영 정보를 숨겼을 때도 선을 표시할지를 설정할 수 있습니다. 선은 촬영 화면에만 표시됩니다.
- **날짜 각인(Date Imprint):** 날짜 형식을 선택합니다. Fn 버튼을 누르면 **날짜 서식(Date Style)**, 그리고 숫자의 글꼴인 **날짜 글꼴(Date Font)**(클래식, GR1s, GR II)을 설정할 수 있습니다. 사진의 오른쪽 아래에 날짜가 들어갑니다. 켜져 있는 동안 촬영 정보를 모두 표시하는 촬영 화면에 DATE가 표시됩니다.
- **입자감(Grain):** 약, 중, 강, 매우 강 중에서 선택합니다. Fn 버튼을 누르면 **크기**를 선택할 수 있습니다: 자동(ISO에 연동), 소, 중, 대. 입자감은 사진에만 들어갑니다.

MENU 버튼을 누르면 한 단계 위로 돌아갑니다. GRKit의 설정은 전원을 꺼도 유지됩니다.

GRKit의 모든 설정은 MENU의 사용자 설정 탭(C) 마지막에 있는 **GRKit** 항목에도 있습니다.

- 모듈마다 행이 하나 있습니다. 첫 번째 설정인 **사용**은 모듈을 바로 켜거나 끕니다. 꺼진 모듈은 ADJ에 표시되지 않습니다. 모듈의 꺼짐 값(프레이밍의 꺼짐 등)을 선택하면 모듈은 ADJ에 남습니다. 그다음에 다른 설정이 이어집니다. 필름 룩에는 효과를 선택하는 **필름 종류**와 선택한 효과의 **파라미터**가 있습니다.
- 필름 룩, 프레이밍, 구도 가이드, 날짜 각인에는 **사용** 다음에 **옵션** 행이 있습니다. 효과, 비율, 가이드 종류, 날짜 형식의 목록이며, 각 값에는 체크 상자가 있습니다. 값에서 OK 버튼을 누르면 체크가 바뀝니다. ADJ에는 켜진 값만 표시됩니다.
- **ADJ 메뉴 순서**는 GRK에서 모듈의 순서를 설정합니다. 모듈을 선택한 다음 새 위치를 선택합니다. 새 순서는 바로 적용됩니다.
- **GRKit 정보**는 GRKit의 버전과 프로젝트 주소를 표시합니다.

`GRKIT/REPORT.TXT`에서 GRKit의 버전을 확인할 수 있습니다.

GRKit은 효과를 `GRKIT/EFFECTS` 폴더에 저장합니다. 새 패키지는 자신의 효과를 추가하고 이전 버전을 바꿉니다. 다른 효과는 삭제하지 않습니다. 효과를 추가하려면 그 파일을 `GRKIT/EFFECTS`에 복사합니다. 다른 패키지의 효과를 추가하려면 그 패키지의 `SD_ROOT/SCRIPT/GRKIT/EFFECTS`에 있는 파일을 `GRKIT/EFFECTS`에 복사합니다. 효과를 `SCRIPT/GRKIT/EFFECTS`에 복사하지 마세요. GRKit은 설치나 업데이트 후 처음 전원을 켤 때만 이 폴더를 읽습니다. 삭제하려면 카메라의 전원을 끄고 그 파일을 삭제합니다. 이후의 패키지는 패키지 안의 파일이 바뀐 경우에만 그 효과를 다시 추가합니다. 모듈을 추가하려면 그 파일을 `GRKIT/MODULES`에 복사합니다. MENU의 GRKit 항목에 있는 필름 룩의 **옵션**에는 각 효과 파일이 표시되며, 필름 룩에서의 표시를 바로 켜거나 끌 수 있습니다. GRKit은 효과를 최대 40개까지, 켜진 것부터 설치합니다. 설치되지 않은 효과를 켜면 다음에 전원을 켤 때 표시됩니다. `GRKIT/REPORT.TXT`에는 지난번 전원을 켰을 때의 모듈과 효과, 그리고 모듈을 불러오지 못한 이유가 기록됩니다.

## 문제 해결

### MENU 버튼을 누른 채 전원을 켜면 펌웨어 업데이트가 시작됩니다

카드 최상위에 펌웨어 업데이트 파일이 있습니다. 카메라의 전원을 끕니다. 카드 최상위에서 `.bin` 파일을 모두 삭제합니다. 그런 다음 3단계를 다시 합니다.

### Mode Set Command가 표시되지 않습니다

- MENU 버튼을 누른 채 전원을 켭니다. 전원을 켠 뒤에 MENU 버튼을 누르면 SD 스크립트는 켜지지 않습니다.
- `SD_ROOT`의 내용은 `DCIM` 같은 폴더가 아니라 카드 최상위에 복사합니다.

### ADJ 모드에 GRK가 표시되지 않습니다

1. 전원을 켜고 몇 초 기다립니다. GRKit은 카메라가 시작된 뒤에 불러와집니다. 불러오기가 끝나면 촬영 화면 위쪽에 **GRKit**이 몇 초 동안 표시됩니다.
2. ADJ 모드에서 GRK를 찾습니다. GRKit의 설정은 MENU의 사용자 설정 탭의 GRKit 항목에도 있습니다.
3. 3단계에서 Mode Set Command가 표시되지 않았다면 3단계를 다시 합니다.
4. 카드 최상위에 `SCRIPT` 폴더가 있는지 확인합니다. `SCRIPT`를 포함해 `SD_ROOT`의 내용을 모두 복사합니다.
5. 카드에 `SCRIPT/GRKIT/INSTALL.ERR`이 있으면 GRKit이 설치되지 않은 것입니다. 카메라에 지원하는 펌웨어 버전이 표시되는지 확인합니다. 펌웨어 버전은 카메라 메뉴에서 확인할 수 있습니다. 버전이 지원된다면 `INSTALL.ERR`, `GRKIT/REPORT.TXT`, `GRKIT/BOOT.TXT`의 내용을 모두 첨부해 [기기 리포트](https://github.com/ahonn/grkit/issues/new?template=device-report.yml)를 보내 주십시오.
6. GRKit은 리코의 공식 펌웨어에서만 작동합니다. 수정된 펌웨어에서는 작동하지 않습니다.

### 카드를 포맷한 뒤 GRKit이 작동하지 않습니다

카메라에서든 컴퓨터에서든 카드를 포맷하면 `SCRIPT` 폴더와 `GRKIT` 폴더가 삭제됩니다. GRKit, GRKit의 설정, 효과가 모두 사라집니다.

1. 카드를 포맷하기 전에 `GRKIT` 폴더를 컴퓨터에 복사합니다.
2. 포맷한 뒤 `SD_ROOT`의 내용을 다시 카드 최상위에 복사합니다.
3. 복사해 둔 `GRKIT` 폴더를 카드 최상위에 다시 넣습니다.

### GRKit이 안전 모드로 시작됩니다

안전 모드에서는 GRKit이 모듈을 불러오지 않으며, `GRKIT/REPORT.TXT`에 그 이유가 기록됩니다. `GRKIT` 폴더에 `SAFE` 또는 `SAFE.TXT`라는 이름의 파일이 있으면 안전 모드로 시작됩니다. 모듈을 다시 불러오려면 그 파일을 삭제합니다.

모듈을 추가한 뒤 카메라가 멈추면 MENU의 사용자 설정 탭의 GRKit 항목에서 그 모듈의 **사용**을 꺼짐으로 설정합니다. MENU를 열기 전에 카메라가 멈추면 카드를 꺼냅니다. 컴퓨터에서 `GRKIT/MODULES`의 그 모듈을 삭제하거나, `GRKIT` 폴더에 `SAFE` 또는 `SAFE.TXT`라는 이름의 빈 파일을 넣습니다.

## 삭제와 복구

GRKit을 삭제하려면 카메라의 전원을 끕니다. 그런 다음 카드에서 `SCRIPT` 폴더와 `GRKIT` 폴더를 삭제합니다. `GRKIT`에는 GRKit의 설정이 들어 있습니다.

SD 스크립트 설정은 켜진 채로 남습니다. 끄려면 다음과 같이 합니다.

1. https://grkit.app에서 사용하는 카메라의 SD 스크립트를 끄는 파일을 다운로드합니다. 버튼은 설치 단계 아래에 있습니다.
2. `SD_ROOT`의 내용을 SD 카드 최상위에 복사합니다.
3. 카드를 넣습니다. MENU 버튼을 누른 채 전원을 켭니다. 카메라의 전원이 저절로 꺼질 때까지 기다립니다.
4. 카드 최상위에서 `00078560.636`과 `DEVELOP.MOD`를 삭제합니다.

시작하는 도중에 카메라가 멈추면 배터리와 카드를 꺼냅니다. 그런 다음 카드를 넣지 않고 카메라를 켭니다. 그래도 시작되지 않으면 [복구 가이드](https://github.com/ahonn/grkit/blob/main/resources/RECOVERY.ko.md)를 참조하십시오.

GRKit은 리코와 제휴 관계가 없습니다. 소스 코드와 라이선스: https://github.com/ahonn/grkit
