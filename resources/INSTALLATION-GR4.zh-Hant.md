# GRKit

僅適用於 RICOH GR IV 與 GR IV HDF 韌體 1.11。
一個套件適用於每個支援的韌體版本。每次開機時，GRKit 會識別相機的韌體。
韌體 1.20（GR IV Monochrome 上為 1.10）的更新無法復原。更新後，同一個套件仍然可以使用。
GR IV Monochrome 執行 GR IV 的韌體，但顯示自己的版本號：韌體 1.11 顯示為 1.00，韌體 1.20 顯示為 1.10。它的套件不含底片風格。GR IV Monochrome 使用 GR IV 的執行環境，但本身未經實機測試。

## 安裝

1. 關閉相機。
2. 把 `SD_ROOT` 中的內容複製到記憶卡根目錄。
3. 插入記憶卡。按住 MENU 按鈕開機。等待相機自動關機。
4. 正常開機。

第 3 步會開啟相機的 SD 腳本功能。相機先顯示 Mode Set Command，接著顯示 Complete，之後自動關機。

![Mode Set Command 畫面顯示 Script - Enable 和 Complete。](images/modeset.png)

如果 SD 腳本功能已經開啟，跳過第 3 步。
安裝完成後，你可以從記憶卡根目錄刪除 `00078560.636` 與 `DEVELOP.MOD`。這一步是選用的。

## 更新

1. 關閉相機。
2. 從記憶卡刪除 `SCRIPT` 資料夾。
3. 把新安裝包 `SD_ROOT` 中的 `SCRIPT` 資料夾複製到記憶卡根目錄。
4. 正常開機，不需要按住 MENU。

GRKit 把設定、效果和你加入的模組保存在 `GRKIT` 資料夾中，所以更新後它們仍在。

刪除 `SCRIPT` 也會刪除 GRKit 1.2 的設定和效果。要保留它們，請在電腦上的 Chrome 或 Edge 中開啟 [grkit.app](https://grkit.app)，透過讀卡機連接記憶卡後更新。

## 使用

在拍攝模式下按下 ADJ 桿進入 ADJ 模式，然後選擇第 6 個功能 GRK。GRKit 在開機幾秒後才載入，所以 GRK 可能稍後才出現。載入完成後，拍攝畫面頂部會顯示 **GRKit** 幾秒。這個提示需要畫幅或輔助線模組。

- **底片風格（Film Look）：** 反白一個效果，即可在實時顯示中預覽。按 OK 按鈕保留這個效果。按 Fn 按鈕調整這個效果的 [標準] 參數。在 GRK 選單的底片風格一列按 Fn 按鈕，可以調整目前選擇的效果。每個效果單獨保存自己的調整，不會改變相機的影像控制設定。這些效果是為 GR III 製作的，所以在 GR IV 上顏色可能不同。
- **畫幅（Framing）：** 選擇 XPan、2.35:1、16:9、4:3、5:4、7:6 或 1:1。選擇任何畫幅時，相機的 [長寬比] 都會設為 3:2，顯示屏仍按 3:2 顯示，照片以外的區域會變暗。相機的 [長寬比] 設為 16:9 時也可以使用 XPan 和 2.35:1。在相機選單中把 [長寬比] 設為其他值時，畫幅暫時不起作用。DNG 檔案保留完整的感光元件影像，並記錄裁切範圍。套用這個裁切範圍的 RAW 軟體只顯示照片區域。
- **輔助線（Guides）：** 選擇一種輔助線樣式。按 Fn 按鈕設定線條顏色、不透明度，以及 DISP 隱藏拍攝資訊時是否顯示輔助線。輔助線只顯示在顯示屏上，不會出現在照片中。
- **加印日期（Date Imprint）：** 選擇一種日期樣式。按 Fn 按鈕設定 **日期樣式（Date Style）** 和數字的 **日期字體（Date Font）**：經典、GR1s 或 GR II。照片右下角會加印日期。開啟期間，顯示全部拍攝資訊時顯示屏上會顯示 DATE。
- **粒紋感（Grain）：** 選擇弱、中、強或特強。按 Fn 設定 **大小**：自動（跟隨 ISO）、小、中或大。粒紋感只加在照片上，不影響影片。

按 MENU 按鈕返回上一層。關機後 GRKit 會保留你的設定。

GRKit 的全部設定也在 MENU 自訂頁（C）最後的 **GRKit** 小節中：

- 每個模組一列。第一項設定**啟用**立即開啟或關閉這個模組。關閉的模組不在 ADJ 中顯示；而模組自己的「關閉」值（例如畫幅中的「關閉」）只關閉效果，模組仍在 ADJ 中。後面是它的其他設定。底片風格中有**膠卷**，用來選擇效果，還有目前效果的**效果參數**。
- 底片風格、畫幅、輔助線和加印日期的設定中，**啟用**之後有**可選項**一列，列出效果、比例、輔助線樣式或日期樣式。每一項前有一個核取方塊，在一項上按 OK 勾選或取消勾選。ADJ 只顯示開啟的項。
- **ADJ 選單順序**：設定模組在 GRK 中的順序。選擇一個模組，再選擇它的新位置。新的順序立即生效。
- **關於 GRKit**：顯示 GRKit 的版本和專案網址。

`GRKIT/REPORT.TXT` 中有 GRKit 的版本號。

GRKit 把效果保存在 `GRKIT/EFFECTS` 資料夾中。新的安裝包會加入它的效果，並取代這些效果的舊版本，但不會移除其他效果。要加入效果，把它的檔案複製到 `GRKIT/EFFECTS`。要加入另一個安裝包的效果，把那個安裝包 `SD_ROOT/SCRIPT/GRKIT/EFFECTS` 中的檔案複製到 `GRKIT/EFFECTS`。不要把效果複製到 `SCRIPT/GRKIT/EFFECTS`：GRKit 只在安裝或更新後第一次開機時讀取這個資料夾。要移除一個效果，先關閉相機，再刪除它的檔案。只有當之後的安裝包中這個效果的檔案有變化時，它才會被重新加入。要加入模組，把它的檔案複製到 `GRKIT/MODULES`。MENU GRKit 小節中底片風格的**可選項**列出每個效果檔案，並立即開啟或關閉它在底片風格中的顯示。GRKit 最多安裝 40 個效果，優先安裝開啟的效果。如果開啟一個沒有安裝的效果，它在下次開機後出現。`GRKIT/REPORT.TXT` 列出上次開機時的模組和效果，以及模組沒有載入的原因。

## 疑難排解

### 按住 MENU 按鈕開機時，相機開始更新韌體

記憶卡根目錄中有韌體更新檔案。關閉相機。從記憶卡根目錄刪除所有 `.bin` 檔案。然後重新執行第 3 步。

### 相機沒有顯示 Mode Set Command

- 先按住 MENU 按鈕，再開機。如果開機後才按 MENU 按鈕，SD 腳本功能不會開啟。
- 把 `SD_ROOT` 中的內容複製到記憶卡根目錄，不要複製到 `DCIM` 或其他資料夾中。

### ADJ 模式中沒有 GRK

1. 開機後等待幾秒。GRKit 在相機啟動後才載入。載入完成後，拍攝畫面頂部會顯示 **GRKit** 幾秒。
2. 在 ADJ 模式中找 GRK。GRKit 的設定也在 MENU 自訂頁的 GRKit 小節中。
3. 如果第 3 步中相機沒有顯示 Mode Set Command，重新執行第 3 步。
4. 確認記憶卡根目錄中有 `SCRIPT` 資料夾。複製 `SD_ROOT` 中的全部內容，包括 `SCRIPT`。
5. 如果記憶卡中有 `SCRIPT/GRKIT/INSTALL.ERR`，表示 GRKit 沒有安裝成功。確認相機顯示的是支援的韌體版本。在相機選單中可以查看韌體版本。如果版本受支援，請提交[裝置報告](https://github.com/ahonn/grkit/issues/new?template=device-report.yml)，並附上 `INSTALL.ERR`、`GRKIT/REPORT.TXT` 和 `GRKIT/BOOT.TXT` 中的全部內容。
6. GRKit 只能在 Ricoh 官方韌體上執行，不能在修改過的韌體上執行。

### 格式化記憶卡後 GRKit 不運作

格式化記憶卡會刪除 `SCRIPT` 和 `GRKIT` 資料夾，無論在相機上還是在電腦上格式化。GRKit、GRKit 的設定和效果都會被刪除。

1. 格式化之前，把 `GRKIT` 資料夾複製到電腦。
2. 格式化之後，再次把 `SD_ROOT` 中的內容複製到記憶卡根目錄。
3. 把備份的 `GRKIT` 資料夾複製回記憶卡根目錄。

### GRKit 以安全模式啟動

在安全模式下，GRKit 不載入任何模組，`GRKIT/REPORT.TXT` 會說明原因。`GRKIT` 資料夾中有名為 `SAFE` 或 `SAFE.TXT` 的檔案時，GRKit 進入安全模式。刪除這個檔案，即可重新載入模組。

如果加入一個模組後相機停止回應，在 MENU 自訂頁的 GRKit 小節中把這個模組的**啟用**設為關閉。如果相機在開啟 MENU 之前就停止回應，取出記憶卡，在電腦上從 `GRKIT/MODULES` 刪除這個模組，或在 `GRKIT` 資料夾中放一個名為 `SAFE` 或 `SAFE.TXT` 的空檔案。

## 移除或復原

要移除 GRKit，先關閉相機。然後從記憶卡刪除 `SCRIPT` 和 `GRKIT` 資料夾。`GRKIT` 保存 GRKit 的設定。

SD 腳本設定會保持開啟。要關閉它：

1. 在 https://grkit.app 下載你的相機對應的關閉 SD 腳本的檔案。按鈕在安裝步驟下方。
2. 把 `SD_ROOT` 中的內容複製到記憶卡根目錄。
3. 插入記憶卡。按住 MENU 按鈕開機，等待相機自動關機。
4. 從記憶卡根目錄刪除 `00078560.636` 和 `DEVELOP.MOD`。

如果相機在啟動時停止回應，取出電池與記憶卡。然後不插記憶卡開機。如果仍然無法啟動，請參閱[復原指南](https://github.com/ahonn/grkit/blob/main/resources/RECOVERY.zh-Hant.md)。
