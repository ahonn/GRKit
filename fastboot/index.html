Fast start

GRKit loads one to two seconds after power-on.

Official firmwareFast-boot firmware
GRKit loadsAbout 8 to 10 seconds after power-onOne to two seconds after power-on
GRKit featuresAllThe same, with the same package

VersionsAll that GRKit supportsGR III 2.21, GR IIIx 1.71, GR IV 1.21, GR IV Monochrome 1.11

Make the firmware

  1. Download the latest firmware of your camera from Ricoh.
    • GR III 2.21
    • GR IIIx 1.71
    • GR IV 1.21
    • GR IV Monochrome 1.11
  2. Select the downloaded ZIP file, or the firmware file in it. The fast-boot firmware downloads.

    The file is not uploaded.

    GRKit is experimental and has no warranty. If you continue, you accept the terms of use.

Install the firmware

Installing it updates the camera firmware. If the update stops, the camera may not start.

  1. Charge the battery fully. Copy your photos from the card.
  2. Copy the fast-boot firmware to the card root, not into a folder. Remove other firmware files from the card root.

    The camera finds the file only by its exact name:

    • GR IIIfwdc239b.bin
    • GR IIIxfwdc243b.bin
    • GR IV / GR IV Monochromefwdc248b.bin

    If the download folder already has a file of that name, the browser adds a number, such as fwdc239b (1).bin. Rename the file on the card back.

    In Windows, turn on File name extensions in File Explorer before you rename. Otherwise the name can become fwdc239b.bin.bin.

  3. Turn the camera off. Hold MENU and press the power button. Keep MENU held until the update screen shows.
  4. Select Execute, and press OK.
  5. The update starts. Do not turn the camera off or open the battery cover until the update is complete.
  6. When the update is complete, turn the camera off.
  7. Turn the camera on, and make sure that it takes and plays back photos. Then delete the firmware file from the card. Fast start needs GRKit 1.5.0 or later. If the card has an older GRKit or none, install the latest as usual.

After that, GRK shows in ADJ soon after power-on. The camera menu shows the same firmware version as before.

No update screen?

  • If the camera starts as usual, it did not find the file. Check the file name, and make sure that the file is in the card root. Then try again.
  • If the camera shows a problem with the update file, make the fast-boot firmware again from the latest official file.

Go back to the official firmware

Open the official ZIP of the same version, and update the camera with the firmware file in it, in the same way. A later official update also replaces the fast-boot firmware.
