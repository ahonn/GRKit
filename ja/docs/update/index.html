ドキュメント / はじめに

アップデートと削除

アップデートしても、設定とフィルムルックは残ります。MENU を押して起動し直す必要はありません。

サイトからアップデート

  1. カードをカードリーダーに入れ、Chrome か Edge でインストールページを開きます。
  2. SD カードを接続を選び、変更内容を確認して、カードに書き込みます。
  3. カードをカメラにセットして、電源を入れます。

ZIP からアップデート

  1. カードから SCRIPT フォルダーを削除します。
  2. 新しい GRKit.zip の SD_ROOT から、SCRIPT フォルダーだけをカードのルートにコピーします。
  3. カードをカメラにセットして、電源を入れます。MENU は押さないでください。

GRKit を削除する

インストールページでカードを接続し、GRKit をアンインストールを選びます。または、SCRIPT フォルダーと GRKIT フォルダーを削除します。写真は残ります。GRKIT には GRKit の設定が入っています。

SD スクリプトをオフにする

GRKit を削除しても、この設定はオンのままです。オフにするのは、GRKit の使用を完全にやめる場合だけにしてください。

  1. インストールページで、お使いのカメラの SD スクリプトをオフにするファイルをダウンロードします。
  2. SD_ROOT の中身をカードのルートにコピーします。
  3. カードをセットします。MENU を押したまま電源を入れます。
  4. 電源が自動で切れるまで待ちます。
  5. カードのルートから ModeSet ファイルと DEVELOP.MOD を削除します。
