ドキュメント / 問題の解決

よくある質問

想定どおりの動作、メモリーカード、スマートフォンへの取り込みについて説明します。

最初の写真にフィルムルックが付かないのはなぜですか？

GRKit が読み込まれるまでは、カメラ本体の設定で撮影されます。高速起動を使うと、待ち時間が短くなります。

DNG が 3:2 のまま、またはフィルムルックが付かないのはなぜですか？

GRKit が変更するのは JPEG です。DNG には RAW データがそのまま残ります。RAW 現像をご覧ください。

保存した BOX でフィルムルックが戻らないのはなぜですか？

カメラの［呼び出し］（GR III/IIIx）や［USER モードBOX 呼び出し］（GR IV）では GRKit の設定は復元されません。レシピか現在の設定を保存を使ってください。

カードをフォーマットするとどうなりますか？

フォーマットすると、GRKit とその設定が削除されます。先に写真と GRKIT フォルダーをパソコンにコピーします。フォーマットの後、GRKit をインストールし、フォルダーをカードのルートに戻します。

スマートフォンに写真を取り込めないのはなぜですか？

GRKit は DCIM フォルダーに何も書き込みません。GR World を最新バージョンにアップデートします。それでもスマートフォンのアプリで失敗する場合は、レポートを送ってください。
