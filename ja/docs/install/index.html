ドキュメント / はじめに

GRKit をインストール

メモリーカードに GRKit を書き込み、SD スクリプトを一度だけオンにします。

カードに書き込む

パソコンの Chrome か Edge とカードリーダーを使います。カメラの USB 接続では書き込めません。

  1. インストールページを開きます。カメラ、ファームウェア、モジュール、フィルムルックを選びます。
  2. SD カードを接続を選びます。カード自体を選び、編集を許可します。
  3. 変更内容を確認して、カードに書き込みます。カードの写真はそのまま残ります。

ほかのブラウザー

  1. インストールページで GRKit.zip をダウンロードします。
  2. SD_ROOT の中身（フォルダー自体ではありません）をカードのルートにコピーします。
  3. カードのルートに SCRIPT フォルダーがあることを確認します。

最初の起動

この手順は一度だけ行います。SD スクリプトの設定は、どのカードでもオンのままです。

  1. カメラの電源を切り、カードをセットします。
  2. MENU を押したまま電源を入れます。
  3. Complete が表示され、電源が自動で切れるまで待ちます。
  4. 通常どおり電源を入れます。
ファームウェアのアップデートが始まった場合カードのルートにファームウェアのファイルがあります。カメラの電源を切り、カードのルートから .bin ファイルをすべて削除して、この手順をやり直します。

GRKit を使う

GRKit は電源を入れてから約 8〜10 秒で読み込まれます。GR IV や、インストール・アップデート後の最初の起動では、もっと時間がかかります。読み込まれると、撮影画面の上部に GRKit が表示されます。

  1. 撮影モードで ADJ を押し、6 番目の項目 GRK を選びます。
  2. 機能を選び、項目にカーソルを合わせます。
  3. OK を押して決定します。Fn を押すと、ほかの設定を開けます。
