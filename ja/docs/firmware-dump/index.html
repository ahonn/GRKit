ドキュメント / カメラ

ファームウェアの書き出し

書き出しツールは、GRKit がまだ認識できないファームウェアのビルドに開発者が対応するためのものです。

始める前にこのツールはメモリーを読み取るだけです。書き出したファイルに写真や個人データは含まれません。SD スクリプトがオンになっている必要があります。このツールがカードにある間、GRKit は読み込まれません。充電済みのバッテリーを使ってください。

ファームウェアを書き出す

  1. 最新リリースから GRKit-<version>-dump.zip をダウンロードします。
  2. カメラの電源を切り、カードを取り出します。
  3. カードの SCRIPT フォルダーをバックアップとしてパソコンにコピーします。
  4. ZIP の SD_ROOT の中身をカードのルートにコピーします。SCRIPT/STARTUP.TTL は置き換えます。
  5. カードをセットして、通常どおり電源を入れます。MENU は押さないでください。
  6. 2 分待ちます。その後、電源を切ります。
  7. パソコンで SCRIPT/GRDUMP を開きます。フォルダーには DUMP.OK か DUMP.ERR があります。
  8. SCRIPT/GRDUMP を ZIP に圧縮し、カメラの機種とファームウェアのバージョンを添えて GitHub issue に添付します。

カードを元に戻す

カードから SCRIPT フォルダーを削除します。その後、バックアップした SCRIPT フォルダーをカードにコピーします。
