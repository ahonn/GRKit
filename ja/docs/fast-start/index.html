ドキュメント / カメラ

高速起動

任意の高速起動ファームウェアを使うと、電源を入れて 1〜2 秒で GRKit が読み込まれます。

カメラのファームウェアを変更しますRicoh 製ではないファームウェアファイルでカメラのファームウェアをアップデートします。アップデートが途中で止まると、カメラが起動しなくなるおそれがあります。改造されたファームウェアを使ったカメラは、Ricoh の保証や修理を受けられないことがあります。

インストールする

  1. Ricoh から、カメラの最新ファームウェアの ZIP をダウンロードします。
  2. 高速起動のページで、その ZIP を選びます。ページがお使いの端末の中で高速起動ファームウェアを作ります。
  3. バッテリーを満充電し、カードの写真をコピーしておきます。
  4. 高速起動ファームウェアのファイルをカードのルートにコピーします。ほかの .bin ファイルは削除します。
  5. カメラの電源を切ります。MENU を押したまま電源ボタンを押し、画面の指示に従います。
  6. アップデートが終わるまで、電源を切ったりバッテリー／カードカバーを開けたりしないでください。
  7. 電源を入れ、撮影と再生ができることを確認します。
  8. カードからファームウェアのファイルを削除します。その後、最新の GRKit をインストールします。

公式ファームウェアに戻す

同じバージョンの公式ファームウェアファイルを、同じ方法でインストールします。以降の公式アップデートでも、高速起動ファームウェアは置き換えられます。
