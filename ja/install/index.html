インストール

  1. カメラの電源を切ります。
  2. GRKit.zip を開きます（ブラウザーによっては自動で展開されます）。SD_ROOT フォルダーそのものではなく、その中身をカードのルートにコピーします。コピー後、カードのルートに SCRIPT フォルダーがあれば OK です。
  3. カードを入れます。初回のみ：MENU ボタンを押したまま電源を入れ、電源が自動で切れるまで待ちます。この手順で 00078350.588 と DEVELOP.MOD を使います。
  4. 電源を入れます。GRKit は電源を入れてから約 8〜10 秒で読み込まれます。その後、撮影画面で ADJ を押し、6 番目の項目「GRK」を選びます。

    GRKit をもっと早く読み込むには、高速起動をお試しください。

  5. 任意：カードのルートから 00078350.588 と DEVELOP.MOD を削除します。アップデートでは使いません。

アップデート

  1. カメラの電源を切ります。
  2. カードから SCRIPT フォルダーを削除します。
  3. 新しい GRKit.zip を開き、SD_ROOT の SCRIPT フォルダーだけをカードのルートにコピーします。
  4. カードを入れて、電源を入れます。MENU ボタンを押しながら電源を入れる必要はありません。
  5. カードにあるフィルムルックはそのまま残ります。不要なものは、MENU の GRKit にあるフィルムルックの「オプション」で非表示にできます。

アンインストール

  1. カメラの電源を切ります。カードから SCRIPT フォルダーと GRKIT フォルダーを削除します。GRKIT には GRKit の設定が入っています。
  2. SD スクリプトもオフにする場合は、下のファイルをダウンロードし、SD_ROOT の中身をカードのルートにコピーします。
  3. カードを入れます。MENU ボタンを押したまま電源を入れ、電源が自動で切れるまで待ちます。
  4. カードのルートから 00078350.588 と DEVELOP.MOD を削除します。

よくある質問

ADJ に GRK が表示されない

GRKit は電源を入れてから約 8〜10 秒で読み込まれます。GR IV や、インストール・アップデート後の最初の起動ではもう少しかかります。少し待ってから、撮影画面で ADJ を押し、6 番目の項目「GRK」を選びます。初回は SD スクリプトをオンにする必要があります。MENU ボタンを押したまま電源を入れてください。もっと早く読み込むには、高速起動をお試しください。

電源を入れた直後の写真にフィルムルックがかからない

GRKit が読み込まれるまでは、カメラ本来の設定で撮影されます。電源を入れてから数秒待つか、高速起動をお試しください。

GRKit はカメラのファームウェアを変更しますか？

いいえ。GRKit は電源を入れるたびに SD カードから読み込まれます。カードを抜くか GRKit をアンインストールすると、カメラは元どおりに動きます。SD スクリプトの設定（カメラがカードの GRKit を実行するための設定）は、オフにするまでオンのままです。ファームウェアを変更するのは、オプションの高速起動ファームウェアをインストールした場合だけです。

GRKit をもっと早く読み込めますか？

はい。オプションの高速起動ファームウェアを使います。ファームウェアの更新が一度必要です。

フィルムルックでイメージコントロールの設定は変わりますか？

いいえ。フィルムルックをオンにすると、イメージコントロールの代わりに使われます。フィルムルックをオフにすると、元のイメージコントロールの設定に戻ります。

カードをフォーマットするとどうなりますか？

フォーマットすると、GRKit とその設定が削除されます。フォーマットの前に GRKIT フォルダーをパソコンにコピーし、フォーマットの後で GRKit をもう一度インストールしてから、GRKIT フォルダーをカードのルートに戻してください。

アップデートや別のカードでも、MENU を押して電源を入れる必要がありますか？

いいえ。MENU を押して電源を入れるのは、SD スクリプトをオンにする初回だけです。この設定はどのカードでも有効です。

自分の LUT や Lightroom のプリセットを使えますか？

はい。「フィルムルック」の「LUT を読み込む」を選びます。Lightroom のプリセットを LUT 画像にする方法は、読み込みウィンドウに説明があります。

これらのルックを Lightroom で使えますか？

そのままでは使えません。GRKit は Lightroom のプリセットを作りません。ルックはオープンソースのフィルム LUT から作られています。ページ下部の「フィルムルックのライセンス」に、各ルックの出典があります。

GRKit が対応しているカメラは？

GR III、GR IIIx、GR IV とそれぞれの HDF モデル、そして GR IV Monochrome（フィルムルックなし）です。ファームウェアはカメラ一覧のバージョンに対応しています。GR II 以前の機種には対応していません。

カードの GRKit のバージョンは？

カメラで MENU を開き、「カスタマイズ設定」の GRKit の最後にある「GRKit について」で確認できます。
