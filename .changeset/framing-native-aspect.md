Selecting a Framing ratio now sets the camera's native aspect to 3:2 in both Crop and Guides Only modes. This lets a composition frame appear after the camera uses another native aspect ratio.

Framing Off clears the selected ratio and preserves the camera's current aspect ratio. Changing only the Framing mode also preserves that aspect ratio.

Crop mode crops JPEG photos to the selected ratio. RAW files now default to the native 3:2 area and preserve the camera's digital crop setting. RAW editors that apply the DNG default crop show this 3:2 area. Embedded previews can still show the selected composition.
